# Security Policy

This repository is part of the Empire of Shadows ecosystem - a set of Discord bots, their
dashboards, and the supporting services behind eosofficial.club.

## Reporting a vulnerability

Please report security issues privately, by email, rather than opening a public issue.

**Email: security@eosofficial.club**

Helpful things to include, as far as you have them:

- what the problem is, and which bot, dashboard or service it affects
- how to reproduce it
- what an attacker could actually do with it
- a suggested fix, if you have one (entirely optional)

If reproducing it would mean accessing data that is not yours, disrupting a live server, or
affecting other members, please stop and describe what you found instead. A clear description of
the flaw is worth more than a proof of concept, and testing against the live services without
permission is not something this policy invites.

## What to expect

These services are built and run by one person alongside other commitments, so this is a
deliberately honest set of expectations rather than a corporate SLA:

- an acknowledgement that your report arrived, within 7 days
- an assessment of whether it is a real issue and how serious, once it has been looked at
- an update when it is fixed, or an explanation if it is not going to be

There is no bug bounty and no payment for reports. Reporters are credited in the relevant
changelog unless you would rather stay anonymous - just say so.

## Scope

In scope: the bots, dashboards, web hub, and support services in this ecosystem, including
authentication and session handling, permission and access checks, and anything that could
expose member data.

Out of scope: vulnerabilities in third-party dependencies, which belong to their maintainers -
though a note about one is still welcome, especially if this project's use of it makes the
problem worse. Reports generated by an automated scanner with no evidence of real impact are
generally not actionable.

Most of this ecosystem is closed source, and the services are hosted rather than installed, so
there is no released version for you to identify. Naming the bot, dashboard or page where you
saw the problem is more useful than a version number.

## Disclosure

Please give a reasonable opportunity to fix the issue before describing it publicly. The
intention is to fix things quickly and to keep you informed while that happens.
